# 📚 Site de Estudos com IA

Projeto de um sistema web que utiliza Inteligência Artificial para auxiliar nos estudos, permitindo gerar resumos, planos de estudo e questões automaticamente.

---

## 🚀 Funcionalidades

- ✏️ Geração de resumos com IA
- 📅 Criação de planos de estudo personalizados
- ❓ Geração de questões para prática
- 🕒 Histórico de gerações salvo em banco de dados
- 🌙 Tema claro/escuro com persistência

## ⚙️ Como rodar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Limkol/Site_de_Estudo_com_IA.git
```

### 2. Configurar backend

Instale as dependências:

```bash
cd backend
npm install
```

Crie um arquivo `.env` na pasta backend. Depois adicione:

```env
GEMINI_API_KEY=SUA_CHAVE_AQUI
PORT=3000
```

Inicialize o servidor:

```bash
npm run dev
```

### 3. Configurar frontend

Instale as dependências:

```bash
cd frontend
npm install
```

Inicialize o site:

```bash
npm run dev
```
